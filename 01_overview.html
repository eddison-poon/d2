Agent Hub Performance Capacity Assessment

Objective, Outcomes & Test Strategy

A management-level plan to establish the relationship between concurrent agents, query throughput, response time, and infrastructure capacity.

1. Overview2. Measurement & Execution3. Management Deliverable

Objective

Establish a measurable relationship between Concurrent Agents → Query Throughput (QPM) → Response Time → Infrastructure Capacity, providing a baseline for current environment assessment and future Agent Hub capacity planning.

Key Outcomes

Maximum sustainable capacityIdentify the maximum QPM within the agreed response-time target.
Supported concurrencyDetermine how many concurrent active agents the environment can support.
Baseline capacity unitEstablish the capacity of a minimum Agent Hub infrastructure configuration.
Saturation indicatorsIdentify infrastructure signals associated with performance saturation.
Scaling behaviourUnderstand how capacity changes as infrastructure instances increase.
Reusable capacity modelCreate a foundation for future environment sizing and growth planning.

Test Strategy

StageTest FocusKey QuestionExpected Outcome
1 — Capacity DiscoveryIncrease concurrent agents using a simple, low-token, repeatable prompt.How many concurrent agents and QPM can the current environment sustainably support?Maximum Sustainable QPM, supported concurrency and saturation point.
2 — Minimum Infrastructure IsolationRepeat the workload using the minimum viable Agent Hub infrastructure.What is the capacity of the smallest infrastructure configuration?Baseline Capacity Unit — QPM and agents supported per minimum deployment.
3 — Infrastructure SamplerCorrelate selected infrastructure metrics with load, throughput and response time.What signals indicate that the platform is approaching capacity?Resource utilisation profile and likely saturation indicators.
4 — Scaling ValidationCompare capacity using selected infrastructure sizes, e.g. 1 → 2 → 4 instances.Does adding infrastructure provide predictable additional capacity?Scaling efficiency and evidence for future infrastructure sizing.
