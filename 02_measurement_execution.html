Execution Approach

Stage 1 — Discover

Establish baseline → progressively increase concurrent agents → identify sustainable capacity → continue toward saturation.

Stage 2 — Isolate

Reduce to minimum viable infrastructure → repeat the controlled workload → establish capacity per infrastructure unit.

Stage 3 — Understand

Sample infrastructure utilisation throughout Stages 1–2 → correlate resource behaviour with QPM and latency → identify saturation indicators.

Stage 4 — Validate Scaling

Test selected instance counts → compare throughput improvement → calculate scaling efficiency → validate capacity assumptions.
